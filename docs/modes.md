# LogLine modes without changing anatomy

## Principle

Modes change semantic pressure, not anatomy. Every mode walks the same 9 slots.

```text
who did this when confirmed_by if_ok if_doubt if_not status
```

## Modes

### Pocket

The small local discipline that prevents language from pretending to be runtime.
It is useful inside LLM workflows and human drafting.

### Grammar

The formal surface that decides whether a sentence has the 9-slot shape and
valid canonical terms.

### Algebra

The symbolic model of routes, statuses, transitions, and consequences.

### Operational

The runtime boundary where evidence, adapters, receipts, and world effects are
handled.

### Closure

The evidentiary layer that records whether a claim is open, simulated,
confirmed, released, rejected, or closed.

## Rule

A mode must never delete a slot. A mode may only increase or decrease the
strictness applied to the same slot structure.
